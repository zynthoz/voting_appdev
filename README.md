# Election Voting System

A role-based web Election Voting System for cooperatives or classes.

## Tech Stack
- PHP (Vanilla)
- MySQL
- HTML / CSS / JS
- PHPMailer

## Setup Instructions
1. Clone or download this project.
2. Put the files into your web server directory (e.g., `htdocs` for XAMPP).
3. Import the SQL file from the `database/` directory.
4. Update SMTP credentials in `includes/mailer.php`.
5. Open your browser and navigate to the application URL.
